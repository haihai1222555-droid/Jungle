# 🧺 Jungle Laundry 2.0

크래프톤 정글 기숙사 세탁실의 **LG 트롬 워시타워 9대(세탁기 + 건조기 = 18개 모듈)** 실시간 현황판.
빨래가 끝나기 5분 전에 폰으로 알림이 오고, 앱을 꺼둬도 온다.

**🔗 https://krafton-jungle.duckdns.org**

---

## 정글러 사용법

### 1. 지금 빈 기기 찾기

접속하면 바로 보인다. 위쪽 **남녀 맞춤 추천**에 지금 쓸 수 있는 기기가 뜬다.
누적 가동 횟수가 가장 적은(= 가장 깨끗한) 기기를 우선 추천한다.

| 구역 | 호기 |
| --- | --- |
| 👦 남성 전용 | 1 ~ 5호기 |
| 🤝 공용 | 6 ~ 7호기 |
| 👧 여성 전용 | 8 ~ 9호기 |

기기 카드를 누르면 상세 정보(코스, 남은 시간, 누적 횟수, 에러 해결법)가 열린다.

### 2. 🔔 알림 걸기 — 핵심 기능

가동 중인 기기 카드의 **[🔔 5분전 알림]** 버튼을 누르면 끝.
**내가 누른 기기만** 추적하고, 안 누른 기기는 절대 알림이 오지 않는다.

받게 되는 알림은 네 가지다.

| 시점 | 내용 |
| --- | --- |
| 완료 5분 전 | 미리 내려갈 준비 |
| 완료 | 바로 수거 |
| **완료 후 15분** | 빨래를 안 꺼냈을 때 **수거 요청** |
| 가동 중 에러 | 배수 막힘 등으로 멈췄을 때 즉시 |

완료 알림이 가면 **등록이 자동으로 해제된다.** 다음 사람이 그 기기를 써도 나에게 알림이 오지 않는다.

빨래를 15분 넘게 안 꺼내면 **수거 요청 알림**이 한 번 더 온다.
그 사이 누군가 기기를 새로 돌리면 (= 빨래를 꺼냈다는 뜻) 알림은 오지 않는다.

> ⚠️ **아이폰은 반드시 홈 화면에 설치해야 한다.**
> 사파리 탭에서는 웹 푸시가 아예 오지 않는다.
> `공유 → 홈 화면에 추가` 로 설치한 뒤, **그 아이콘으로 실행해서** 알림을 허용할 것. (iOS 16.4+)
>
> 안드로이드는 크롬으로 접속해 알림만 허용하면 된다.

폰과 노트북에 각각 걸어두면 **양쪽 모두** 알림이 온다.

### 3. 언제 가면 안 밀리나

**24H 골든타임** 카드에서 시간대별 혼잡도를 볼 수 있다.
심야 21~02시가 제일 붐비고, 새벽 02~08시가 가장 여유롭다.

상단 신호등은 지금 이 순간 비어있는 기기 수를 5단계로 보여준다.

### 4. AI 비서

자연어로 물어보면 실시간 기기 상태를 반영해 답한다.

```
"지금 남성 구역에 바로 쓸 수 있는 세탁기 있어?"
"수건 냄새 안 나게 하려면 어떤 코스로 돌려?"
"건조기 dE4 에러 떴는데 어떻게 해?"
```

### 5. 사이트 안에서 사용법 보기

헤더의 **[📖 사용법]** 버튼을 누르면 이 문서의 핵심이 사이트 안에서 바로 열린다.
팀원에게는 링크만 주면 된다.

### 6. 앱처럼 쓰기

브라우저 메뉴에서 **홈 화면에 추가**하면 앱처럼 설치된다 (PWA).
우상단 버튼으로 다크/라이트 테마를 바꿀 수 있다.

## 🤖 디스코드 봇

같은 데이터를 디스코드에서도 쓸 수 있다. **말을 걸면 알아듣는다.**

```
DM 으로 또는 @봇 멘션으로
  "3번 건조기 알림 걸어줘"   →  등록
  "해제해줘"                →  방금 말한 그 기기를 해제 (문맥 기억)
  "남는 세탁기 있어?"        →  목록 + 배치도 그림
```

멘션 없이 채널에서 그냥 말하게 하려면, 그 채널에서 **`/채널설정`** 을 누른다.
(다시 누르면 해제. 재배포가 필요 없다)

단 메시지 내용을 읽으려면 개발자 포털에서 **MESSAGE CONTENT INTENT** 를 켜고
`ENABLE_MESSAGE_CONTENT=1` 을 줘야 한다. 포털에서 켜지 않고 이 값만 주면
봇이 접속하지 못하는데, 그때는 스스로 그 기능을 끄고 다시 켜서 멘션/DM 은 살린다.

### 명령어

| 명령어 | 역할 |
| --- | --- |
| `/비서 <말>` | 자연어로 알림 걸기 |
| `/채널설정` | 이 채널에서 멘션 없이 대화 (토글) |
| `/알림` | 배치도 이미지 + 기기 선택 |
| `/내알림` | 버튼으로 켜고 끄기 (🔔 초록 = 등록됨) |
| `/세탁기` `/건조기` | 9대 현황 |
| `/정보` | 사용법 |
| `/알림테스트` | 알림 3종을 DM 으로 바로 받아 확인 (버튼 포함) |
| `/버그` | 버그 제보 · 개선 제안 (관리자에게 DM 으로 전달) |
| `/업데이트` | 최근에 무엇이 바뀌었는지 |

명령어는 AI 가 멈춰도 쓸 수 있는 안전망이다.
문장을 읽는 일은 AI 가 맡고, AI 가 둘 다 막혔을 때만 규칙으로 처리한다.
(규칙을 먼저 쓰던 때가 있었는데, 말이 조금만 달라져도 어긋나서 순서를 뒤집었다)

### 알림 (DM 으로 온다)

완료 5분 전 · 완료 시 · **완료 후 15분간 안 가져가면 수거 요청** · 가동 중 에러.
완료 알림의 `가져갔어요` 를 누르면 수거 요청을 보내지 않는다.
기기에서 값이 3분 넘게 안 오면 완료로 단정하지 않고 "확인이 어렵다" 고 한 번만 알린다.
다음 사람이 새로 돌리면 자동 해제된다.

### 봇은 따로 띄우지 않는다

`start_server.py` 가 웹과 봇을 한 프로세스에서 함께 띄운다.
`DISCORD_BOT_TOKEN` 만 있으면 자동으로 붙고, `RUN_DISCORD_BOT=0` 을 주면 웹만 뜬다.

**`DISCORD_BOT_TOKEN` 은 절대 깃에 올리지 말 것.** `.env` 는 `.gitignore` 에 있다.

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| 남녀 맞춤 추천 | 구역별 최적 기기 + 빈 기기 수 |
| 실시간 점검 알리미 | 에러 기기, 통살균 필요 기기 (누적 30회 초과) |
| 혼잡도 신호등 | 5단계 실시간 혼잡도 + 24시간 골든타임 |
| 워시타워 그리드 | 9대 카드. `📋 기본 카드` / `🏢 현실 배치` 두 가지 뷰 |
| 세탁 치트시트 | 옷 종류별 코스, 에티켓 |
| AI 비서 | 자연어 질문 (텍스트 / 음성) |
| 알림 도크 | 내가 추적 중인 기기 목록 (하단 고정) |
| 📖 사용법 | 헤더 버튼 → 사용 안내 모달 |
| 🐞 제보 | 왼쪽 아래 버튼 → 버그·개선 제안 (관리자에게 DM) |

휴대폰(768px 이하)에서는 **9대를 한 화면에 담는 압축 카드**로 바뀐다.
카드에서 바로 🔔 알림을 걸 수 있고, 남은 시간 옆에 늘어날 수 있는 시간(`+10~20분`)이 붙는다.
자리를 위해 점검 알리미와 치트시트는 감춰지고, 기기 현황이 맨 위로 올라온다.
큰 화면은 그대로다.

## 구조

```
브라우저 ─→ Oracle Cloud (krafton-jungle.duckdns.org)
              ├─ 사이트 (index.html / app.js / style.css)
              ├─ /api/status, /api/stats  → 원본 서버 프록시
              └─ 알림 등록 + 5초마다 감시 + 발송
                    ↑
UptimeRobot ─→ /api/health  5분마다 핑 (죽으면 알림)
Upstash     ←─ 알림·설정·제보 보관 (재시작해도 안 사라진다)
```

`start_server.py` 하나가 **사이트 서빙 + API 프록시 + 알림 발송**을 모두 담당한다.
세탁기 원본 데이터는 외부 서버(Cloudflare 터널)에서 받아온다. **이 프로젝트 소유가 아니다.**

### 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 골격 |
| `app.js` | 렌더링, 알림 엔진, AI 챗봇 (빌드 도구 없는 순수 JS) |
| `style.css` | 다크/라이트 테마, 반응형 |
| `start_server.py` | 서버 (정적 서빙 + 프록시 + 웹푸시 워커) |
| `sw.js` / `manifest.json` | PWA 설치, 백그라운드 푸시 수신 |

### API

| 엔드포인트 | 용도 |
| --- | --- |
| `GET /api/status` | 9대 실시간 상태 |
| `GET /api/stats?days=7` | 누적 가동 통계 |
| `GET /api/health` | 서버 상태 + 등록된 알림 수 |
| `GET /api/vapid-public-key` | 푸시 구독용 공개키 |
| `POST /api/subscribe-push` | 알림 등록 |
| `POST /api/unsubscribe-push` | 알림 해제 |
| `POST /api/test-push` | **즉시 테스트 알림 발송** |
| `POST /api/chat` | AI 챗봇 (서버 경유 시) |

## 로컬 실행

```bash
cp jungle_kb.example.py jungle_kb.py    # 안내 지식 (아래 설명 참고)
pip install -r requirements.txt
python start_server.py
```

`http://localhost:8000` 에서 열린다. 윈도우는 `run.bat` 을 실행해도 된다.
VAPID 키(`vapid_private.pem`)가 없으면 자동 생성된다.

Docker 로도 된다.

```bash
docker compose up -d --build
```

## 배포

`start_server.py` 하나만 띄우면 된다. systemd 서비스로 두고 앞에 Caddy 를 세워
HTTPS 를 맡기는 구성이다. 자세한 절차는 **[DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)** 참고.

### 환경변수

| Key | 필수 | 설명 |
| --- | --- | --- |
| `VAPID_PRIVATE_KEY_PEM` | ✅ | 푸시 서명용 개인키. 없으면 재시작마다 키가 바뀌어 **기존 알림이 전부 무효화된다** |
| `TARGET_BASE` | | 원본 API 주소. 주소가 바뀌면 **여기만** 바꾸면 된다 (코드 수정·재배포 불필요) |
| `STALE_PICKUP_SEC` | | 수거 요청 알림까지의 유예 시간 (기본 900초 = 15분) |
| `PORT` | | 실행 포트 (기본 8000) |
| `SUBS_FILE` | | 알림 구독 저장 경로 |
| `DISCORD_BOT_TOKEN` | | 있으면 봇도 함께 뜬다 |
| `RUN_DISCORD_BOT` | | `0` 이면 웹만 띄운다 |
| `GEMINI_API_KEY` `..._2` `..._3` | | 여러 개를 넣으면 막힌 키를 건너뛴다 |
| `GROQ_API_KEY` | | 제미나이가 늦거나 막혔을 때 쓰는 예비 엔진 |
| `UPSTASH_REDIS_REST_URL` / `..._TOKEN` | | 알림·설정·제보를 밖에 보관 (재시작해도 유지) |
| `SUPPORT_CONTACT` | | 문의처. 비워 두면 번호 없이 안내한다 |
| `ADMIN_USER_IDS` | | 제보를 DM 으로 받을 관리자 |

## 문제 해결

### 알림이 안 올 때

**1) 서버가 살아있는지**

```bash
curl https://krafton-jungle.duckdns.org/api/health
```

`{"ok": true, "webpush": true, "alarms": N}` 이 나와야 한다.
`webpush: false` 면 `VAPID_PRIVATE_KEY_PEM` 환경변수가 빠진 것이다.

**2) 전달 경로 점검 — 빨래 끝날 때까지 기다릴 필요 없다**

알림을 등록한 뒤 아래를 실행하면 **즉시** 테스트 알림이 온다.

```bash
curl -X POST https://krafton-jungle.duckdns.org/api/test-push -H "Content-Type: application/json" -d "{}"
```

**3) 서버 로그 확인**

```bash
tail -f ~/jungle-laundry/server.log
```

| 로그 | 의미 |
| --- | --- |
| `[WebPush] 백그라운드 알림 워커 시작됨` | 서버 정상 기동 |
| `[Alarm] 5분전 조건 충족: ...` | 발송 조건 판정됨 |
| `[Alarm] 완료: ...` | 완료 알림 발송, 이후 수거 여부 감시 시작 |
| `[Alarm] 방치 감지: ...` | 완료 후에도 안 꺼내서 수거 요청 발송 |
| `[WebPush] 발송 성공: ...` | 실제 발송 완료 |
| `[WebPush Error] ...` | 판정은 맞았으나 전송 실패 — 원인이 여기 찍힌다 |

`[Alarm]` 도 안 뜨면 판정 문제, `[Alarm]` 은 뜨는데 `발송 성공` 이 없으면 전송 문제,
둘 다 떴는데 폰에 안 오면 폰 권한 / iOS 설치 방식 문제다.

### 알림 소리가 안 날 때

웹 푸시는 코드로 소리를 지정할 수 없다. **안드로이드 알림 채널 설정**이 결정한다.
`설정 → 앱 → Chrome(또는 설치한 앱) → 알림 → 채널 → 중요도`를 **기본 이상**으로 올린다.

### 숫자가 안 바뀔 때

화면 상단에 **"연결 끊김 · N분 전 데이터"** 로 표시된다.
원본 서버가 꺼졌거나 터널 주소가 바뀐 것이다. 이때도 마지막으로 받은 데이터를 계속 보여준다.
`TARGET_BASE` 환경변수를 새 주소로 바꾸면 복구된다.

## 알아둘 제약

* **원본 서버는 이 프로젝트 소유가 아니다.** 그쪽이 꺼지면 실시간 데이터가 끊긴다.
  무료 Cloudflare 터널이라 재시작하면 주소도 바뀐다.
* **시간대별 혼잡도는 한 주가 지나야 제 값이 된다.** 서버가 5초마다 직접 세어
  쌓는 실측값이라, 24시간이 다 차기 전에는 화면이 추정치를 쓴다.
  매주 월요일에 지난 주 관측으로 갱신된다.
* **AI 챗봇 API 키가 클라이언트 코드에 있다.** 브라우저가 제미나이를 직접 부르는
  구조라 그렇다. 팀 내부용 전제로 둔 것이며, 공개 서비스로 쓰려면
  서버를 거치도록 바꿔야 한다. 키가 모두 막히면 로컬 규칙 응답으로 대체된다.
* **디스코드 봇과 웹은 같은 프로세스에서 돈다.** 봇을 두 대에서 동시에 띄우면
  알림이 두 번 간다. 서버를 옮길 때는 옛 쪽을 먼저 멈춰야 한다.

## 안내 지식은 저장소에 없다

`jungle_kb.py` 와 `assets/` 사진은 **기관 내부 자료라 올리지 않는다.**
출결·공가·벌점 규정, 연락처, 시설 사진 같은 것들이라 공개할 성격이 아니다.

대신 본보기를 뒀다. 복사해서 자기 자료로 채우면 된다.

```bash
cp jungle_kb.example.py jungle_kb.py
```

| 채울 것 | 내용 |
| --- | --- |
| `BASE` | 매 질문마다 함께 보낼 기본 정보 (짧게) |
| `SECTIONS` | 주제별 안내. `keywords` 에 걸리면 그 항목만 골라 보낸다 |
| `IMAGES` | 질문에 맞춰 보낼 사진. `assets/` 에 같은 이름으로 넣는다 |
| `LINK_BLOCK` | 답변 끝에 붙일 링크 목록 |

**없어도 돌아간다.** 세탁실 기능은 그대로고 생활 안내만 답하지 못한다.

문의처는 `.env` 의 `SUPPORT_CONTACT` 로 받는다. 비워 두면 번호 없이 안내한다.
