1. 수집하는 항목 (전체)

아래가 이 서비스가 다루는 정보의 전부입니다.

가. 저장되는 것

디스코드 사용자 ID 알림을 개인 DM으로 보내기 위해 필요합니다. 숫자로 된 식별자이며, 이것만으로는 이름·이메일을 알 수 없습니다. 알림을 걸 때
알림 신청 내용 기기 번호(1~9호기), 세탁기/건조기 구분, 기기 이름, 신청 시각, 예상 완료 시각, 알림 발송 여부. 알림을 걸 때
디스코드 표시 이름 디스코드에서 제보를 남긴 경우에만, 누가 남겼는지 확인하기 위해 함께 기록합니다. 디스코드로 제보할 때
제보 내용 버그·개선 제안으로 직접 작성한 글 (최대 1,000자). 웹에서 남기면 익명이며 작성자를 알 수 없습니다. 제보할 때
웹 푸시 구독 정보 브라우저 알림을 켠 경우, 브라우저가 발급한 구독 주소(endpoint)와 암호화 키. 누구인지 식별할 수 없는 값입니다. 브라우저 알림을 켤 때
채널 ID 디스코드 채널에서 멘션 없이 대화하도록 설정한 경우, 그 채널의 번호. 개인이 아닌 채널 정보입니다. /채널설정 을 쓸 때
혼잡도 통계 시간대별로 몇 대가 가동 중이었는지 세는 숫자입니다. 누가 썼는지는 기록하지 않습니다. 항상 (자동 집계)

나. 잠시 메모리에만 두는 것 (저장 안 함)

대화 내용 봇이나 웹 AI에게 보낸 질문과 답변. 앞뒤 맥락을 잇기 위해 최근 8개까지 10분 동안만 메모리에 둡니다.
마지막 대화 문맥 “그거 취소해줘” 같은 말을 알아듣기 위한 직전 기기 정보. 5분 유지.
관리자 세션 관리자 모드를 켠 경우 그 사용자 ID와 시각. 30분 뒤 자동 종료.
사용자 프로필 캐시 DM을 보내기 위해 조회한 디스코드 사용자 정보. 같은 사람에게 반복 조회하지 않으려는 것으로, 서버 재시작 시 사라집니다.
IP 주소 웹에서 제보할 때, 같은 사람이 30초 안에 반복 전송하는 것을 막기 위해 메모리에만 잠시 둡니다. 1시간 뒤 정리되며 파일이나 로그로 남기지 않습니다.

수집하지 않는 것 — 이름, 학번, 전화번호, 이메일, 주소, 생년월일, 성별, 위치, 결제 정보, 기기 고유식별자, 쿠키를 이용한 광고 추적.

접속 기록 — 웹 서버와 중계 서버 모두 방문자 IP를 접속 로그로 남기지 않도록 운영합니다. 오류 발생 시 원인 파악을 위한 기록에는 개인을 식별할 정보가 포함되지 않습니다.

2. 이용 목적

  • 세탁·건조 완료 5분 전과 완료 시점에 알림을 보내기 위해
  • 가져가지 않은 빨래를 15분 뒤 한 번 더 알리기 위해
  • 질문에 답하고 세탁실 현황을 안내하기 위해
  • 시간대별 혼잡도를 계산해 한산한 때를 추천하기 위해
  • 버그를 고치고 기능을 개선하기 위해
  • 제보가 한꺼번에 쏟아지는 것을 막기 위해 (IP, 메모리에만)

위 목적 외의 용도로는 쓰지 않습니다.

5. 이용자의 권리

  • 알림 삭제 — 디스코드에서 /내알림 으로 언제든 해제할 수 있습니다.
  • 웹 알림 해제 — 브라우저 설정에서 알림 권한을 끄면 즉시 중단됩니다.
  • 열람·삭제 요청 — 남아 있는 정보의 확인이나 삭제를 원하면 /버그 또는 웹의 🐞 제보 버튼으로 알려주세요. 확인 후 처리하고 결과를 알려드립니다.
  • 이용 중단 — 알림을 모두 해제하면 저장된 정보가 남지 않습니다.

6. 보호 조치

  • 웹은 HTTPS로 암호화해 주고받습니다.
  • API 키 등 비밀값은 코드가 아닌 서버 환경변수에 두며, 답변에 섞여 나가지 않도록 걸러냅니다.
  • 제보 내용에 포함된 멘션은 무력화해 다른 사람을 호출할 수 없게 합니다.
  • 필요한 최소한만 받고, 목적이 끝나면 지웁니다.
